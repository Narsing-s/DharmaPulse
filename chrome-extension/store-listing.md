# Chrome Web Store listing

## Short description
A daily Dharma companion with devotional wisdom, mantras, deity images and optional reminders.

## Detailed description
DharmaPulse brings a small daily devotional moment into Chrome.

Features:
- Daily Dharma message
- Rotating deity focus
- Fresh deity imagery discovered from Wikimedia Commons
- Daily mantra and wisdom
- New blessing action for a fresh selection
- Save a favorite locally
- Optional daily Chrome reminder
- Configurable reminder time
- One-click access to the full DharmaPulse web app
- No account required
- No paid API required

Privacy:
DharmaPulse stores preferences and favorites locally in Chrome storage. Deity image discovery uses Wikimedia Commons when the popup requests an image. The extension does not request browsing history, bookmarks, cookies or page access.

Permission justification:
- alarms: schedule the optional daily reminder.
- notifications: display the optional daily DharmaPulse reminder.
- storage: save reminder preferences and the local favorite.
- commons.wikimedia.org / upload.wikimedia.org: retrieve and display deity artwork/images selected by the user or daily rotation.
