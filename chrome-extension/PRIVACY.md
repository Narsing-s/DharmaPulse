# DharmaPulse Chrome Extension — Privacy

DharmaPulse works without an account, analytics, advertising, or browsing-history collection.

The extension stores only reminder/language preferences in Chrome local storage. The popup and reminder service worker retrieve devotional content from the public DharmaPulse GitHub repository. The extension does not sell personal information or run advertising trackers.

If reminders are enabled, Chrome notifications are used for the daily Dharma reminder. Users can disable them at any time.
