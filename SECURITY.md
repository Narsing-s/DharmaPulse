# Security Policy

## Supported versions

Security fixes are applied to the actively maintained `main` branch. Older snapshots may not receive security fixes.

## Reporting a vulnerability

Please do **not** report security vulnerabilities through public GitHub issues.

Use GitHub's **Private Vulnerability Reporting** feature for this repository when available. If it is unavailable, contact the repository maintainer privately through GitHub and provide enough information to reproduce the issue.

Please avoid publicly disclosing sensitive details until the issue has been reviewed and addressed.

## Security practices

- Never commit secrets, tokens, credentials, or private keys.
- Keep dependencies and build tooling updated.
- Minimize permissions requested by browser features and the Chrome extension.
- Keep user data local wherever practical.
- Run the repository's automated quality checks before submitting changes.
